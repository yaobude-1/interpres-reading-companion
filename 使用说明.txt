Interpres · 使用说明
==============================

名字取自拉丁语：interpres —— 译者、解读者。
一个 Windows 小工具：在任意程序里选中外文，点「译」按钮就能翻译，
查词会优先用本地词典（带变位/变格），也能把生词存进 Anki。

第一次使用
------------------------------
1. 解压后进入文件夹，双击里面的「Interpres.exe」。
   它是绿色版，数据保存在用户目录，不安装系统服务。
   注意：exe 没有数字签名，Windows 可能弹出安全提示；是否继续运行由你决定。

2. 按 Ctrl + Alt + S 打开设置面板。

3. 「模型」里填 API Key：
   - 到 https://platform.deepseek.com 注册，创建 Key，复制粘贴进来
   - 服务地址保持默认 https://api.deepseek.com/v1
   - 点「测试连接」确认通了，再点「保存」

4. （可选）「词典设置…」里添加自己的 MDX/MDD 词典：
   - 格式：MDict 的 .mdx（可配同名 .mdd 提供图片/音频）
   - 只支持未加密的 MDX 2.0
   - 不配词典也能用，只是查词会走 AI

怎么用
------------------------------
· 选词：在书里选中一个单词 → 自动弹出「译」按钮 → 点开是词典卡片
· 选段：选中一句话/一段话 → 弹出「译」按钮 → 点开是翻译
· 查词卡片上有「原版」按钮，可以看词典的原始排版
· Ctrl + Alt + S：打开设置面板（标题上会显示版本号）
· 面板「查词」标签可以手动输入单词查
· 生词可以加入生词本，同步到 Anki（需要本机装 Anki 并开启 AnkiConnect）

数据存在哪
------------------------------
%USERPROFILE%\.reading-companion\
   config.json      设置（含 API Key）
   reading.db       生词本 / 翻译记录 / 对话记录
   app.log          运行日志

换电脑时把整个文件夹拷过去就行。

更新版本
------------------------------
更新时不需要卸载，也不用重新配置：

1. 先完全退出正在运行的程序（面板右上角 ✕）
2. 用新的「Interpres.exe」覆盖旧的
3. 重新双击打开

设置、生词本、翻译记录都在 %USERPROFILE%\.reading-companion 里，
和 exe 分开存放，覆盖 exe 不会丢。

怎么确认有没有更新成功：打开设置面板，标题会显示版本号；
也可以右键 exe → 属性 → 详细信息，看「文件版本」。

常见问题
------------------------------
· 双击时报 "Failed to extract VCRUNTIME140.dll / Permission denied"：
  单文件 exe 启动时要解压运行库，偶尔被杀软或上一次的残留进程挡住。
  关掉错误框、等几秒再双击一次通常就好；反复出现就把 exe 所在目录加入杀软信任。
· 没有反应？检查是否按了 Ctrl+Alt+S，或看任务栏有没有图标。
· 翻译失败？多半是 API Key 没填或余额不足，「测试连接」能看到具体报错。
· 查词说没词典？去「词典设置…」添加 MDX。
· 想换配色？设置 →「原版配色…」，有 4 套预设，也能逐项改颜色。
· 浏览器里的网页被当成"书"了？设置 →「书名过滤…」，
  把网页标题里出现的词加进去（比如 知乎、Bilibili），以后就自动忽略。
· 退出程序：面板右上角 ✕（默认关闭即退出，可在设置里改）。

不需要安装 Python，也不需要联网安装依赖，双击即用。

（原名"阅读伴侣"，改名只是换显示名称，旧数据照常可用。）
