Interpres · 使用说明
==============================

名字取自拉丁语：interpres —— 译者、解读者。
一个 Windows 小工具：在任意程序里选中外文，点「译」按钮就能翻译，
查词会优先用本地词典（带变位/变格），也能把生词存进 Anki。

第一次使用
------------------------------
1. 解压后进入文件夹，双击里面的「Interpres.exe」。
   它是绿色版，数据保存在用户目录，不安装系统服务。
   注意：exe 没有数字签名，Windows 可能弹出安全提示；是否继续运行由你决定。

2. 按 Ctrl + Alt + S 打开主面板，点右上角齿轮进入设置。

3. 「连接与 AI」里填 API Key：
   - 到 https://platform.deepseek.com 注册，创建 Key，复制粘贴进来
   - 服务地址保持默认 https://api.deepseek.com/v1
   - 点「测试连接」确认通了，再点「保存」

4. （可选）「词典设置…」里添加自己的 MDX/MDD 词典：
   - 格式：MDict 的 .mdx（可配同名 .mdd 提供图片/音频）
   - 只支持未加密的 MDX 2.0
   - 不配词典也能用，只是查词会走 AI

怎么用
------------------------------
· 选词：在书里选中一个单词 → 自动弹出「译」按钮 → 点开是词典卡片
· 选段：选中一句话/一段话 → 弹出「译」按钮 → 点开是翻译
· 查词卡片上有「原版」按钮，可以看词典的原始排版
· Ctrl + Alt + S：打开主面板（设置从右上角齿轮进，标题会显示版本号）
· 想换主题/浮窗大小？设置 →「外观」：深色/浅色、强调色、浮窗宽度/高度/透明度、主界面透明度
  （主题和强调色重启后生效，尺寸/透明度下次打开窗口生效）
· 浮窗也能直接拖四边/四角缩放；双击上/下边缘恢复“高度随内容自适应”
· 面板「查词」标签可以手动输入单词查
· 点「聊」可以围绕选中的文字对话；Edge/Chrome 里会自动读取它所在的段落，其他阅读器可以手动补充
· 自动读取可以在 设置 →「翻译与对话」里关闭；“对话原文上限”默认 4000 字，可自行调整
· 生词本里双击一个单词，可以弹出它的词典卡片（没词典时显示保存的释义/例句）
· 生词表右上角可以按单词/释义搜索；点列头可以排序，下次打开还按你选的顺序
· 生词可以加入生词本，同步到 Anki（需要本机装 Anki 并开启 AnkiConnect）

数据存在哪
------------------------------
%USERPROFILE%\.reading-companion\
   config.json      设置（含 API Key）
   reading.db       生词本 / 翻译记录 / 对话记录
   app.log          运行日志

换电脑时：生词本、翻译记录可以直接拷；但 API Key 用 Windows DPAPI 加密，
只能在同一台电脑、同一个 Windows 用户下解密——换机或换用户后需要重新填一次 Key
（设置面板会明确提示“无法解密”，不会再假装你没配置）。

卸载
------------------------------
程序是绿色版，本身没有安装器。要卸载时，运行程序目录里的 uninstall.ps1：

  右键「uninstall.ps1」→ 使用 PowerShell 运行
  （或在该目录打开 PowerShell：powershell -ExecutionPolicy Bypass -File .\uninstall.ps1）

它会：
1. 退出正在运行的 Interpres；
2. 删除桌面和开机自启里的 Interpres 快捷方式；
3. 问你是否删除 %USERPROFILE%\.reading-companion 里的生词本、翻译记录和设置；
   直接回车 = 保留，输入 y = 删除；
4. 删除程序目录（如果提示删不掉，手动删掉这个文件夹即可）。

只想换电脑/重装：可以保留数据目录，下次打开会自动接着用。

更新版本
------------------------------
更新时不需要卸载，也不用重新配置：

1. 先完全退出正在运行的程序（面板右上角 ✕）
2. 用新版本的整个文件夹覆盖旧文件夹（exe 和 _internal 要一起换；
   只换 exe 会和 _internal 里的运行库对不上）
3. 重新双击打开

设置、生词本、翻译记录都在 %USERPROFILE%\.reading-companion 里，
和程序分开存放，覆盖程序不会丢。

怎么确认有没有更新成功：打开设置面板，标题会显示版本号；
也可以右键 exe → 属性 → 详细信息，看「文件版本」。

常见问题
------------------------------
· 双击时报 "Failed to extract VCRUNTIME140.dll / Permission denied"：
  这是早期“单文件 exe”版本的问题；现在的发布版是文件夹版，请确认
  Interpres.exe 和 _internal 文件夹放在同一目录。若仍报错，把该目录加入杀软信任。
· 没有反应？检查是否按了 Ctrl+Alt+S，或看任务栏有没有图标。
· 翻译失败？多半是 API Key 没填或余额不足，「测试连接」能看到具体报错。
· 查词说没词典？去「词典设置…」添加 MDX。
· 想换配色？设置 →「原版配色…」，有 4 套预设，也能逐项改颜色。
· 浏览器里的网页被当成"书"了？设置 →「书名过滤…」，
  把网页标题里出现的词加进去（比如 知乎、Bilibili），以后就自动忽略。
· 退出程序：面板右上角 ✕（默认关闭即退出，可在设置里改）。

不需要安装 Python，也不需要联网安装依赖，双击即用。

（原名"阅读伴侣"，改名只是换显示名称，旧数据照常可用。）
