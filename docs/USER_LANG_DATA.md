# 用户词形与变位表

给词典没收录的变形补“变形 → 原形”，或者导入一张变位表。数据只保存为
JSON，不执行代码；优先级高于词典精确匹配和内置规则。

## 入口

`设置 → 语言与发音 → 词形与变位表…`

- **用户词形**：一行一个 `变形 → 原形`，适合零散不规则形式；
- **从词典提取…**：填好原形后点它，扫描该语言词典里的 `@@@LINK` 重定向，勾选真正的变形后一键加入；
- **批量提取整本词典…**：扫描一次，按相似度阈值批量加入所有 `@@@LINK` 变形；可先预览数量和示例；
- **用户变位表**：一个原形一条表，可以包含任意多个时态组；导入后表里
  每个形式都会自动进入反查索引；
- 支持 `导入 JSON/CSV`、`导出`、`删除选中`、`预览`。

首次扫描大词典可能需要 30–60 秒，结果会缓存在
`<data-dir>/cache/dict_redirect/`，之后同一本词典很快。词典没有
`@@@LINK` 变形（例如部分 Oxford-Hachette 版本）时，提取会返回空。

## 数据位置

```
<data-dir>/lang_data/<lang>.json
```

Windows 默认数据目录可在设置里看到；文件可以手动编辑，改完重启应用生效，
或在对话框里重新导入。

## 格式

```json
{
  "forms": {
    "parlo": "parlare",
    "vado": "andare"
  },
  "tables": {
    "parlare": [
      {
        "key": "present",
        "zh": "现在时",
        "fr": "Presente",
        "rows": [
          ["io", "parlo"],
          ["tu", "parli"],
          ["lui/lei", "parla"],
          ["noi", "parliamo"],
          ["voi", "parlate"],
          ["loro", "parlano"]
        ]
      }
    ]
  }
}
```

- `forms`：键是变形（大小写不敏感），值是原形；
- `tables`：键是原形，值是一个时态组列表；
- 每个时态组必须有 `rows`，每行两个字符串：`[人称/说明, 形式]`；
- `key`/`zh`/`fr` 都可省略，界面会显示能拿到的部分；
- 表里每行的第二个字段会自动加入 `forms` 的反查索引，不需要重复填写。

## CSV

词形导入也接受两列 CSV（可带表头）：

```csv
form,lemma
parlo,parlare
vado,andare
```

## 多语言

导入文件可以是单语言（上面那种），也可以是按语言代码分组：

```json
{
  "it": {"forms": {"parlo": "parlare"}},
  "es": {"forms": {"hablo": "hablar"}}
}
```

对话框会按语言代码分别合并。

## 冲突与优先级

1. 用户词形 / 用户表
2. 词典精确词头
3. 去重音精确
4. 内置词形还原
5. 词典重定向
6. 模糊匹配

同一形式对应多个原形时，来源栏会并列显示；用户数据命中时带
「用户词形 / 用户提供」徽标，不会冒充词典。
